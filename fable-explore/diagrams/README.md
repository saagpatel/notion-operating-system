# Fable diagram set

Four public-safe, standalone SVG diagrams shared by the essay and interactive explainer:

1. `three-protocols-one-system.svg` — data shape selects protocol and guarantee.
2. `write-ladder.svg` — five progressively blunter managed-section write rungs.
3. `receipt-loop.svg` — the outbox-to-page receipt loop and its crash-window repair.
4. `weekly-orchestration-gate.svg` — dry preflight gates every live weekly write.

The files use the explainer's ledger palette and system fonts. Each SVG has an accessible title and description, a `1200 760` viewBox, direct labels, and no external dependencies. They are local source assets only; nothing here publishes or integrates them into a site.
